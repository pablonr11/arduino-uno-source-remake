# Arduino-uno-source-remake

The idea of this project is to remake some of the Arduino source functions myself for the Arduino UNO R3.
This project is not intended to replace the original Arduino code, but rather to learn about the functionality and development of microprocessors.

The ATMega328P is the target microprocessor for this project. It's the microprocessor used in the Arduino Uno R3, which makes it fairly easy to start learning since there's plenty of information available online.
